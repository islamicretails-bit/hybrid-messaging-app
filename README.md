# Hybrid Messaging & Large File Transfer Platform

A modern, high-performance web application designed for multi-mode messaging, low-latency video calls, and massive file transfers.

## 🚀 Features
- **10+ Hours Video & Large File Transfers:** AWS S3 Multipart Upload streaming (Up to 50GB support).
- **Universal Messaging:** Supports both SIM SMS and WhatsApp messaging via Twilio.
- **Real-Time Video Calling:** WebRTC peer-to-peer connection with Socket.io signaling.
- **Dynamic Mode Switch:** Internet vs. Cellular SIM mode support.
- **Lightweight Architecture:** Optimized for low-RAM systems (Vanilla JS & Modern CSS).

## 🛠️ Tech Stack
- **Backend:** Node.js, Express, Socket.io, AWS SDK v3, Twilio
- **Frontend:** HTML5, CSS3 (Glassmorphism), Vanilla JavaScript
